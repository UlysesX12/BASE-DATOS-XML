# BASE-DATOS-XML

Colección de documentos XML de ejemplo para explorar estructuras de datos.

## Contenido

| Grupo | Archivos |
| --- | --- |
| Bases de datos | [BasesDeDatosOO.xml](BasesDeDatosOO.xml), [BasesDeDatosOR.xml](BasesDeDatosOR.xml), [BasesDeDatosXML.xml](BasesDeDatosXML.xml) |
| Programación | [ProgramacionJava.xml](ProgramacionJava.xml), [ProgramacionPHP.xml](ProgramacionPHP.xml) |
| Aulas | [aula1.xml](aula1.xml), [aula2.xml](aula2.xml), [aula3.xml](aula3.xml) |
| Otros ejemplos | AntonioBernal.xml, IsabelGranados.xml, JesusLozano.xml y RobertoGarcia.xml |

## Uso

Clona o descarga el repositorio y abre los archivos con un editor compatible con XML. El repositorio contiene documentos de datos; no incluye un servidor de base de datos ni una aplicación que instalar.

Repositorio mantenido en la cuenta **UlysesX12**. No se ha añadido una licencia nueva ni se ha alterado el contenido de los documentos. Antes de reutilizarlos o distribuirlos, comprueba su procedencia y los permisos aplicables.
